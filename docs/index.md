# Local AI Harness

Изолированный локальный агент на базе Ollama с mTLS-гейтвеем.
Модель работает без доступа к интернету, читает и предлагает
изменения только в пределах одной папки, и записывает файлы лишь
после явного подтверждения пользователем.

## Для кого

- Разработчикам, которым нужно обработать документы или код локальной
  моделью, не отдавая данные наружу.
- Администраторам, которым нужно запустить LLM на своей машине с
  понятной моделью угроз и минимальными привилегиями.
- Исследователям, которым нужен предсказуемый tool-calling агент без
  скрытых сетевых вызовов.
- Командам, которым нужен один локальный LLM-эндпоинт с разными
  правами для разных клиентов (агент с tools, chat-only UI,
  инструментальные интеграции).

## Что решает

- **Изоляция.** Модель физически не имеет выхода в интернет: пять
  Docker-сетей с `internal: true`, единственный сетевой канал —
  `api_call` через локальный прокси с белым списком маршрутов.
- **Ограничение файловой системы.** Чтение и запись — только в
  пределах `./workspace`, с белым и чёрным списками, NFKC-нормализацией
  путей и защитой от symlink escape.
- **Ручное подтверждение записи.** Одна запись на сессию, пользователь
  видит diff и вводит одноразовый код.
- **Защита от самоинъекции.** Файлы, записанные в текущей сессии,
  нельзя прочитать в той же сессии.
- **Multi-client доступ.** mTLS-гейтвей: клиентский сертификат +
  токен, профили (tools, system prompt, rate limit) на каждого
  клиента, единый аудит.
- **Воспроизводимость.** Модели загружаются с sha256-манифестом,
  Python-зависимости — через `uv.lock` с хешами и cooldown'ом.

## Чего не делает

- Не защищает пользователя от собственных действий: если вы вручную
  переименуете `notes/instructions.txt` в `.sh` и запустите — это уже
  вне песочницы.
- Не проверяет содержимое уже существующих в `workspace/` файлов:
  ответственность за чистоту входных данных — на пользователе.
- Не завершает mTLS-handshake в Python: TLS терминируется nginx-
  sidecar, Python верифицирует сертификат по подписи CA. См.
  `docs/design-notes.md`.
- Не является multi-tenant системой: модель угроз — «одна машина, один
  оператор, ручное подтверждение».
